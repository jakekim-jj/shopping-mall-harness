# 그 외 경미한 기록들 (M1, M2, M3)

우선순위는 낮지만, 검색에 걸릴 수 있게 남겨둔다.

## M1 — 서버 에러 메시지가 화면에 안 뜨고 콘솔에만 남음
- 결함 아님으로 판정됨. 서버가 지금은 문구를 하나만 보내서 실질 손실 없음.
- **주의할 점**: 나중에 백엔드가 상황별로 다른 에러 메시지를 보내기 시작하면,
  프론트도 그 메시지를 화면에 노출하도록 같이 바꿔야 한다. 한쪽만 바꾸면 안 됨.

## M2 — 로딩/빈/에러 상태에서 리스트 요소는 DOM에 있지만 숨겨져 있음
- 정상 동작(요구사항대로). 하지만 **이후 테스트 코드를 짤 때** "리스트가 보여야 한다"고
  무조건 단언하면 빈 상태/에러 상태 테스트에서 오탐(false fail)이 난다.
- **주의할 점**: 새 화면에 테스트를 짤 때, "요소가 DOM에 존재하는지"와 "지금 보이는지"를
  구분해서 단언할 것.

## M3 — 이미지 에러 리스너 등록 순서
- 현재는 문제없이 동작. 견고성 차원의 개선 여지만 있음. 우선순위 낮음.
